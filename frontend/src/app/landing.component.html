SECURITY ARCHITECTURE

Enterprise security by default

Engineered with defense-in-depth security controls verified at every layer.

Cookie Session Security

HttpOnly, SameSite, Secure cookie-based authentication with session fixation protection and brute-force rate limiting.

Role-Based Access Control

Enforced across all project boundaries. Transitions verify assignee status, and administrative operations require APP_ADMIN authority.

Comprehensive Audit Trail

Every status transition, assignment change, field edit, and external activity event is logged to an append-only audit trail.

Hardened Security Headers

Strict Content-Security-Policy (CSP), HSTS (max-age 31536000), X-Content-Type-Options nosniff, and X-Frame-Options DENY on every response.
